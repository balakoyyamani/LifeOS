Build a production-quality full-stack web application called **LifeOS — Personal Career & Life Operating System**.

The application is a personal productivity, career-management, learning, fitness, reading, and daily-routine system. Its purpose is to help a user structure each day around measurable goals, track execution, monitor career progress, and generate useful insights from their historical data.

IMPORTANT:

* Do not build a generic habit tracker.
* The application should feel like a professional personal operating system.
* Prioritize a clean, modern, responsive UI.
* Mobile-first design is important because the user will primarily use the application from a phone.
* Build the application modularly so new features can be added without rewriting existing functionality.
* Do not create fake functionality or placeholder buttons that do nothing.
* Every visible button should either work or be clearly marked as coming later.
* Do not over-engineer the first version.

==================================================

==========================
